# Architecture

## Ownership

Theorem and RustyRed own capability semantics, the versioned host lifecycle,
the product route table, tool descriptions, and durable receipts. This
repository packages those capabilities for Claude Code, Codex, and MCP clients.
It owns host manifests, hook bindings, a stdio relay, local host utilities, and
the explicitly declared binary/Ghidra engine.

`theorem-harness-package` renders the hook script, native client, relay, route
table, and capability manifests from `theorem-harness-core`. The downstream
checker verifies generated bytes, behavior-bearing file ownership, and local
relative imports. Product JavaScript must not introduce another capability
compiler, route policy, tool catalog, or semantic fallback.

## Requests and lifecycle

Claude Code and Codex invoke the generated hook. The hook supplies facts only
the host can know, such as its event payload and checkout identity, then sends
the event to native Theorem MCP operations. The Rust runtime normalizes the
event, compiles any context packet, and records receipts. A failed native call
is surfaced as a degraded result; it is not replaced by a local simulation.

The stdio MCP server creates the generated relay with four host utilities:
bounded local `grep`, endpoint `doctor`, `remote_doctor`, and bundled
capability scorecards. Native tool descriptions come from the configured
Theorem endpoint's `tools/list`. Native calls retain their declared semantic
owner, transport, and effect in the route receipt. HTTP routes use the endpoint
origin or the configured `THEOREMS_HARNESS_HTTP_URL`.

The route table also declares one external engine,
`ghidra-headless+local-build-toolchain`, for binary-from-source reconstruction.
The relay calls it only for a matching reconstruction mode. That operation
requires explicit confirmation before running local build commands, copies
the source into a temporary sandbox, and may submit Ghidra facts to native
Datawave ingestion.

## Degraded behavior

The generated client has no implicit localhost endpoint or local semantic
fallback. An unconfigured endpoint, HTTP error, timeout, or native tool error
is returned as a typed degraded response. `doctor` reports native catalog
reachability and the scorecard summary; it does not claim that hooks,
coordination, or receipts have been exercised in a live host session.

`remote_doctor` probes service health, readiness, queue behavior, dependency
isolation, and tenant guardrails. Configure `THEOREMS_HARNESS_REMOTE_URL` for
those probes. Scorecard targets describe measurements to collect and are not
evidence that a target has been met.
